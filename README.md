# 🛒 Projeto Educacional — Website Worten (Clone)

Este repositório contém um projeto desenvolvido no âmbito do curso **Software Developer** do **CESAE Digital**.  
O objetivo é recriar parcialmente a interface do website da Worten, aplicando conhecimentos de:

- HTML5  
- CSS3  
- Bootstrap 5  
- JavaScript  
- Boas práticas de estruturação e organização web  

Este projeto é **estritamente educacional** e não possui qualquer afiliação oficial com a marca **Worten**.

---

## 🚀 Funcionalidades

- Estrutura completa com **header sticky**, **main responsivo** e **footer fixo**
- Página de produtos com cartões responsivos em Bootstrap
- Sistema de navegação completo
- Design inspirado na identidade visual da Worten
- Placeholder cards com animações Bootstrap
- Páginas base: Home, Sobre, Produtos, Promoções, Contactos
